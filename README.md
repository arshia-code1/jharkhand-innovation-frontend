Jharkhand Societal Innovation Platform

A web-based platform designed to help citizens report societal challenges and encourage collaboration between universities, industries, and government departments in Jharkhand.

Features

- Responsive website interface
- Societal challenge listing and details
- Citizen problem reporting interface
- University and industry information pages
- Login and registration interfaces
- Collaboration workspace interface

Technologies Used

- HTML5
- CSS3
- JavaScript

Project Status

Frontend development is in progress. Backend integration will be added later.

Repository Scope

This repository currently contains the frontend code of the project.

Author

Developed as part of the Smart India Hackathon (SIH) project initiative.
